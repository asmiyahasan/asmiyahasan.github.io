Teach an agent tic‑tac‑toe

This agent starts out knowing only the rules. After every game you play, it updates its opinion of each position it saw, so if you beat it the same way twice, it starts to block you. You can also let it practise against itself and watch its win rate go up.

How it learns

The agent keeps a table with one number for every position it has seen: its estimate of how likely that position is to end well for the player who just moved there. Every number starts at 50, meaning "no idea". To choose a move, it looks at the positions each move would lead to and picks the one with the highest number, except that every so often it tries a random move instead, to discover things it would never otherwise try.

After each game it walks back through the positions both players moved to, nudging each one towards the value of the position that came next, and the last one towards the result.
